# Objective

Transform my portfolio into a portfolio that convinces a US AI startup founder to interview me.

This is NOT a designer portfolio.

It is an engineering portfolio.

--------------------------------------------------

# Visitor Journey

Within 5 seconds the visitor should know:

Who am I?

What do I build?

Why should they hire me?

--------------------------------------------------

# Hero Section

Immediately communicate:

Current Role

Specialization

Current company

One-line value proposition.

Avoid generic words like:

Software Engineer

Full Stack Developer

Passionate Programmer

--------------------------------------------------

# Projects

Projects should become case studies.

Every project must contain:

Problem

Solution

Architecture

Key technical decisions

Tech stack

Challenges

Business impact

GitHub

Live demo (if available)

--------------------------------------------------

# Experience

Don't copy the resume.

Instead explain:

What systems you built.

What ownership you had.

What problems you solved.

--------------------------------------------------

# Visual Design

Keep minimal.

Lots of whitespace.

Readable typography.

No excessive animations.

Animations should support usability.

--------------------------------------------------

# Technical Credibility

Include:

Resume download

GitHub

LinkedIn

Tech Stack

Hackathon

--------------------------------------------------

# Remove

Progress bars

Skill percentages

Random icons

Buzzwords

Long paragraphs

Anything that looks like a student portfolio.

--------------------------------------------------

# SEO

Proper page title

Meta description

OpenGraph image

favicon

--------------------------------------------------

# Performance

Lighthouse target:

Performance >95

Accessibility >95

Best Practices >95

SEO >95

--------------------------------------------------

# Mobile

Fully responsive.

No layout shifts.

--------------------------------------------------

# Acceptance Criteria

✓ Founder understands what I build in under 5 seconds.

✓ Projects read like engineering case studies.

✓ No duplicated resume content.

✓ Professional visual design.

✓ Resume, GitHub and LinkedIn are one click away.

✓ Loads in under 2 seconds.

✓ Looks like a portfolio of an engineer working at a funded startup, not a college student.

Finally give a score out of 100 and list remaining improvements.
